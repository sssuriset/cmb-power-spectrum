# Interpretation

The CMB temperature power spectrum shows how temperature anisotropy varies with angular scale. The multipole moment ell is inversely related to angular size on the sky. A rough conversion is:

    theta approx 180 / ell

where theta is in degrees.

## First Acoustic Peak

The first acoustic peak is usually located near ell around 220. This corresponds to an angular scale close to one degree. It is associated with the sound horizon scale at recombination and is one of the most visible features in the CMB power spectrum.

## Higher Acoustic Peaks

The second and third acoustic peaks occur at larger ell values, which correspond to smaller angular scales. These peaks reflect additional compression and rarefaction modes in the photon-baryon fluid before recombination.

## Peak Spacing

Peak spacing gives a simple way to describe the repeated acoustic structure of the spectrum. This project computes spacing in ell between detected peaks. It does not use the spacing to estimate cosmological parameters.

## Limits of This Project

This project identifies spectrum features but does not perform full cosmological parameter fitting. A complete analysis would require a physical CMB model, likelihood estimation, uncertainty treatment, and comparison with parameters such as baryon density, dark matter density, curvature, and the Hubble constant.
